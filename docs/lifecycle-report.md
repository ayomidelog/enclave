## Warm tier

The warm tier is every cycle after the first, which is the steady state a
workspace sees once its rootfs is in the page cache. The cold cycle is reported
on its own because it pays for filling that cache, and one number covering both
would describe neither.

## Reproducing

```bash
ENCLAVE_LIVE_ITERATIONS=12 ./tools/perf/lifecycle-report.sh
```

This needs a privileged host with a cached rootfs at `/root/.local/state/enclave/sandboxes/rootfs-cache/bookworm` and runs against
a daemon it starts in its own state directory, so it does not touch a sandbox
that is already running.
